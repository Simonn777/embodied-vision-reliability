## Operator and information

Freeze qualified SAM2.1-tiny in CPU float32 eval mode, with native BF16 stored memories. Lift a stored BF16 current spatial memory to float32, form a bounded residual, add it and cast back to BF16. At deployment, apply after emitting the current mask and encoding its native memory; preserve frame-zero prompt memory, pointers, positions, ages, mask policy and capacity. All later states are regenerated in the student's own causal rollout.

Residual family: 64 channels, each with standardized centered spatial basis and constant basis. Two coefficients per active channel; exactly zero-variance channels have both zero. Measured finite-precision 2x2 Gram defines total per-channel mean-square energy. Radius B = rho * sqrt(sum(channel variance)). Radial measured-energy projection occurs before BF16; report the actual post-BF16 change separately. This is a restricted channel-affine family, not a new affine modulation invention.

Causal head: 131->128 GELU->128 MLP, output layer initially zero. Inputs are signed log1p of 64 memory means, log1p of 64 standard deviations, current object-score sigmoid, current selected predicted IoU, and current binary mask area. Inputs are detached. Reshape output to 64x2, multiply each channel by rho*sigma, then apply the shared energy projection. No future feature or label is an input. All learned controls have exactly this head.

## Fixed-context training

Use 12 unique anchors per TRAIN parent at integer frames 1 + floor(i*(T-5)/11), i=0..11. Future offsets are 1 and 3. The source write always exists in both futures' six recent nonconditioning slots. Other stored baseline memories, pointers and future image features are detached and fixed. Recompute attention and decoder for each changed source memory. This is not recurrent BPTT.

Each future loss is mean pixel BCE on native-selected raw pre-presence-gate low-resolution logits plus BCE on object presence. GT is nearest-neighbor resized to 256x256, selected target ID only; 255 is background as in the official semisupervised evaluator. Native quality selection and BF16 cast use their explicit PyTorch gradient surrogate. Average the two future losses with sequential backward calls to free graphs.

Teacher: start q=0; perform five measured-Gram steepest-descent updates, direction G^-1 grad and step length B/3 in the Gram norm, then project to the same ball. Evaluate objective at states 0 through 5. Select the earliest minimum-loss state for the multistep target, and the earliest minimum among states 0 and 1 for the one-step ablation. Selecting teacher states uses TRAIN losses only. Targets never leave the head's residual family. Preserve all losses, coefficients and BF16 changed-entry counts. No claim that a privileged target is causally predictable.

GT-memory control: encode the current TRAIN GT binary mask with the same frozen image features and native memory encoder, using native mask-prompt binarization and GT presence. Resize the original mask bilinearly with antialias to 1024 and threshold at 0.5, then use +/-10 logits directly in `_encode_new_memory(is_mask_from_pts=True)`. This is the native memory encoder with a specified GT mask, not a claim of reproducing the predictor's full mask-prompt/preflight resizing chain. Cast that memory to BF16. Fit its difference from baseline in the same measured family and project to the same bound.
