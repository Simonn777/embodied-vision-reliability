# Local storage-mask learning: targeted prior check

2026-10-20; source-only. No experiment, scientific arrays, new labels, model or payload download. This is a bounded comparison, not a novelty certification.

**Conclusion.** Learned mask-guided memory-content improvement is already a direct MemSAM precedent. Learning a representation for later segmentation rather than merely matching the current label is also an explicit LWL precedent. The proposed frozen-encoder, storage-only mask correction is a narrower architectural/experimental question; the inspected evidence neither establishes it as a new contribution nor rules out a useful empirical distinction.

**Exact overlap and remaining distinction.** The broad operator “learn something from the predicted mask/features and improve what is written for later use” is covered. Our proposed operation instead emits the native current mask, leaves the native pointer unchanged, modifies a separate single-channel storage mask, and passes that mask through an unchanged pretrained SAM2 memory encoder. The inspected MemSAM module does not implement that precise bottleneck or native-output/pointer separation. These are restrictions and integration choices, not by themselves an innovation claim. In particular, multiplying a multi-channel feature map by a mask and changing a mask before a nonlinear frozen encoder are not algebraically identical.

**LWL.** Bhat et al., [*Learning What to Learn for Video Object Segmentation*, ECCV 2020](https://www.ecva.net/papers/eccv_2020/papers_ECCV/papers/123470766.pdf): fresh method read §§3.2–3.3, 3.5–3.6, Eqs. (2)–(5), especially PDF pp. 6–7 and 9–10. LWL learns a multi-channel label encoding and spatial importance weights for an internal differentiable target-model learner. Subsequent-frame segmentation losses train those modules through that learner; inference updates target-model parameters using predicted-mask samples. Consequently, “future-task supervision chooses a useful representation” is not new. The inspected mechanism does not keep SAM2 frozen and train only a causal storage-mask corrector, nor regress a separately optimized per-write memory target. That architectural distinction does not establish a new learning principle.

**The meaningful conditional comparison.** Use the identical causal mask head, frozen encoder, inputs, admissible TRAIN masks, write schedule and budget for: (i) current-mask denoising, written only to storage; (ii) direct future segmentation-loss training; and, only if proposed, (iii) optimized-target regression. Native current output and pointer must be kept fixed in all these storage-only arms. A benefit unique to (ii)/(iii) on their own causal rollouts would support a task-dependent storage representation beyond ordinary denoising. Equal performance with denoising would not support that distinction. A privileged GT-storage or optimized-target diagnostic alone cannot establish learnability, deployment benefit or novelty. MemSAM is a substantive content-level precedent; LWL precludes claiming future-supervised representation learning as the contribution.
