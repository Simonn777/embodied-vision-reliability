# Saved TRAIN teacher targets: task alignment diagnostic

Prepared before execution. No change to campaign, family, head, teacher, rollout, data or metric code. No model/tensor/annotation read is authorized by preparing these files.

This is a privileged, fixed-context TRAIN diagnostic: all 48 already-trained anchors from dog-agility, planes-water, dogs-scale and dog-gooses, with both saved future horizons +1 and +3. It asks whether the saved selected `multistep` coefficients improve the actual native selected **post-presence** mask at original resolution, alongside the teacher's raw-mask-plus-presence surrogate loss. It neither learns new coefficients nor selects a new teacher step. There are exactly 96 future `_track_step` calls and no image encoder, zero-baseline replay, optimization, DEV or protected validation calls.

`replay.py` reuses the unchanged qualified `common.load_runtime`, `train.Cache`, `train.example` and `train.future_loss`. A temporary `_track_step` wrapper captures `result[1][3]` without changing the return. The whole replay uses `torch.no_grad()`, the frozen eval model and actual saved `multistep` coefficients, including the original BF16 conversion. Native bilinear interpolation (`align_corners=False`) and threshold `>0` produce original-resolution masks. Baseline masks are taken from their exact cache files at the same future frames. Only the corresponding already-exposed TRAIN annotation PNGs are decoded.

Unchanged `evaluate_jf.jf` supplies separate J and F: target object identity is taken from cache metadata, 255 is background in the official semisupervised convention, and the Euclidean boundary radius is `ceil(.008*hypot(H,W))`. No foreground union or object reassignment. This **horizon-set target-object diagnostic is not the official all-object DAVIS aggregate**. Keep all 96 events, including the four final frames reached by the final anchor's +3 horizon; flag these explicitly. Repeated future frames remain separate anchor-context events, not independent samples. Aggregate the two horizons within each anchor, the 12 anchors within each parent and the four parents equally. Keep every raw pair, both components, paired differences, all selected-loss values and surrogate replay differences; no gain gate or success-subset means.

Inputs, model/native inventory and sources are hash bound. The receipt saves all teacher prediction descriptors, baseline/annotation descriptors, call counts, zero-coefficient parity if encountered, wall time and full native history/position/pointer before/after hashes. Recheck used cache files, target file, labels, metadata and sources at completion; verify unchanged frozen weights via the existing lifecycle. The existing complete-operation supervisor supplies actual outer time/RSS and clean exit, with four CPU threads, 8 GiB and 1800 seconds. Failure preserves partial outputs and does not create a completed result.

CLI: `QUALIFIED_PYTHON -B -S -W error replay.py SPEC.json`.

The source-bound spec includes existing runtime keys `repo`, `native_root`, `native_commit`, `seed:0`, `rho`, `family_root`, `cache`, `cache_receipt_sha256`, and the exact four `train_sequences` above; add `campaign_root`, `evaluator`, fresh `output`, and `bindings` with `{path,sha256,bytes}` descriptors for `teacher_receipt`, `targets`, `mapping` and `data_index`. `source_sha256` must include this script, current `common.py`/`train.py`, unchanged `family.py`/`head.py` and `evaluate_jf.py`. Parent supplies the reviewed completed teacher/cache descriptors; this script does not build another operation-admission framework.

Interpretation: positive TRAIN fixed-context J/F would locate a downstream metric benefit in the privileged targets, while leaving learnability and causal rollout transfer unresolved. Lower surrogate loss with absent or negative native J/F benefit would demonstrate objective/task misalignment in this tested context. Neither outcome alone proves the cause of DEV rollout harm, nor admits deployment, held-out efficacy or a new method.
