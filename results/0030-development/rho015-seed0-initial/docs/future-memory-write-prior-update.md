# Bounded follow-up: future supervision and causal memory-write targets

2026-10-20. Source-only update during the first development campaign. No model, fit, cache, array, mask, GT, checkpoint or campaign-result access. This is not a novelty certification or an experiment/protocol change.

**Finding:** this small search found a close additional precedent for retrospective SAM2 supervision distilled into later causal segmentation, but no inspected source established the exact proposed memory-write target. The distinction remains narrow and empirical: whether amortizing several TRAIN-only optimization steps on a bounded memory-content residual improves a causal learner over the same head trained directly from the same future losses.

**DiTTA — Bootstrapping Video Semantic Segmentation Model via Distillation-assisted Test-Time Adaptation.** Jihun Kim, Hoyong Kwon, Hyeokjun Kweon and Kuk-Jin Yoon; [arXiv:2604.10950v1](https://arxiv.org/html/2604.10950v1), 13 April 2026. Preprint status is what this read verifies; no conference acceptance was checked. Full HTML methods §§3.1–3.3 and protocol §4.2 were read. §3.2 explicitly uses **bidirectional SAM2 propagation** to generate object-consistent masks; semantic labels come from the image segmenter's reliability-weighted predictions. Equation 5 distills those labels into current and temporally propagated logits. Equations 6–8 add object-prototype contrastive feature alignment. Its warm-up-then-freeze protocol adapts on an initial video segment and freezes the learner for subsequent inference. It therefore directly precedes the broad recipe “temporally richer SAM2 targets teach a causal, cheaper predictor.” It does not describe optimizing a stored SAM2 memory embedding against future dense GT and learning to predict that embedding change. Its student, supervision and deployment object also differ: semantic segmenter plus a temporal add-on, rather than the frozen SAM2 decoder with corrected spatial memory writes. This source is a concrete neighboring mechanism, not an exact counterexample to the current operator.

**SAM2-Lite — repository-level claim, lower evidential status.** The [Roshan20222/SAM2-Lite README](https://github.com/Roshan20222/SAM2-Lite) describes matching teacher cross-attention distributions over past frames and memory-readout features, plus learned top-k memory pruning. Only its public README/method summary was read. Its citation calls the work a 2024 arXiv preprint but supplies no identifier; publication status, training implementation and numerical claims were not independently verified. Do not use its claimed results as a qualified baseline. The described target is imitation of teacher attention/readout, not a future-loss-optimized write. It is an additional reason to avoid broad “memory-aware distillation” novelty wording, not decisive evidence about the exact target.

The current distinction should be written as an **operator and comparison**, not a generic teacher/student contribution: freeze native SAM2; use future TRAIN labels to optimize a constrained correction to the present write while other cached memories remain fixed; regress the optimized correction from causal statistics; regenerate all later states in the learner's own rollout. This is not recurrent BPTT or full-tensor unconstrained refinement. The existing one-step, GT-memory and direct same-head controls already address its main alternative explanations. In particular, a multi-step advantage must survive both the same-update and actual complete-cost comparisons; lower teacher training loss alone is insufficient. If direct training matches the causal rollout at equal cost, the substantive optimization-efficiency distinction disappears even if teacher targets differ algebraically. Conversely, a positive pilot would only motivate broader validation; it would not establish new mathematics, future-information identifiability, unseen-source generalization or superiority to every memory-learning method.

No new evidence was found here that changes the earlier LWL/DiMP/OOKD/MobileVOS/EdgeTAM/LiVOS/Cutie/SAM2RL/QDMN/MemSAM/MemTrack assessment. They were deliberately not reread. Exact absence remains uncertain: only three narrowly worded queries were used, and a missed title or differently named operation could contain closer coverage.
