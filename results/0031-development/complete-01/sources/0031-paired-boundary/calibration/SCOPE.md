# Global native-output calibration control — prepared, not executed

This is an ordinary supervised calibration baseline, not a proposed contribution. No model is constructed, no encoder/decoder/head runs, and no stored history, pointer or memory is changed. Source preparation has not opened scientific tensors, masks or evaluation outcomes.

`calibrate.py SPEC.json` uses the existing qualified CPython 3.12.13 environment with normal site initialization, `-B -W error`, four thread environment variables, and a complete supervised operation bounded by 1800 seconds and 8 GiB. It imports Torch only for `weights_only=True` cache deserialization and the original interpolation arithmetic. It never calls `common.load_runtime` or imports SAM2. Runtime admission remains the dispatcher's existing qualified-environment responsibility.

The worker reuses `common.start/save/sha`, the unchanged legacy-cache admission in `evaluate_rollout.admit`, and `evaluate_jf.jf/_means`. Its source set also binds the baseline producer and the installed native interpolation/presence-gating source files. The complete cache receipt, clean original outer/spec/log chain, complete annotation mapping, and data index are bound before any tensor or annotation decode. All selected input bytes are checked before use and again before completion.

**Observation and parity.** Cached `frame-*.pt["out"]["pred_masks"]` is the native selected, post-presence float32 256×256 logit tensor. It is resized to the original shape with PyTorch bilinear interpolation and `align_corners=False`, matching `_get_orig_video_res_output`; single-object non-overlap adds no change. Every read frame must reproduce its saved native NPZ mask exactly at `logits > 0` before its annotation is decoded. Hard-absent native outputs must remain the stored −1024 logits; all five allowed thresholds preserve empty output. No pre-presence surrogate or new presence decision is used.

**TRAIN selection.** Fixed thresholds are `[-2,-1,0,1,2]`. Four original TRAIN parents use their unchanged 12 anchors and futures +1/+3: all 96 events, 87 unique future frames. Repeated events retain their original weight. Each parent averages its 24 events; the selection objective is the equal mean of four parent J/F averages. All events—including four final-frame events—are retained, so this is a TRAIN horizon-set objective using official pixel formulas, not official sequence-endpoint aggregation. Select maximum J&F, then smallest absolute threshold, then smaller threshold. Save all five candidates' parent and per-event J/F and lock `train-selection.json` **before any DEV annotation decode**.

**DEV evaluation.** Only the selected scalar and zero are evaluated on all 154 raw frames of cat-girl/upside-down. Both endpoint metrics remain in the output; primary sequence means exclude first and last, yielding 150 included frames. Parents receive equal weight. Actual initial target IDs come from the completed baseline metadata; 255 is background under the unchanged evaluator. No per-object, per-video or DEV-selected threshold is available.

Outputs are `train-selection.json`, `evaluation.json` (all raw DEV selected/native metrics and per-parent/pooled differences), and the complete/failure `receipt.json` with input fingerprints, 241 unique-frame exact-parity checks, zero model calls, and worker wall time. The external supervisor supplies full-operation wall/RSS/log/exit evidence. No new mask copies are needed to replay this deterministic scalar control.

The adjacent template is intentionally non-executable until the parent fills absolute paths and SHA/byte descriptors and binds its own current source hashes. Parent review/admission precedes execution. No source, data split or previous campaign artifact is modified.
