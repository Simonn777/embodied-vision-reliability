# Final targeted check: center-conditioned residual blind-spot features

2026-10-18. **No exact match found in the three methods inspected. This does not establish global novelty.** The proposed representation remains eligible for a small synthetic mechanism/counterexample test; it is not yet a selected CVPR contribution. No dataset/weight download, model execution, cloud activity, repository edit or paid service. This closes the bounded search.

Target: for each prediction pixel `i`, keep the original noisy target `y_i`, but supply only `z_j^(i)=y_j−(C_ji/C_ii)y_i`, `j≠i`, as neighborhood features. This is different from adding independent noise, subsampling, or learning a visible branch without this covariance projection.

## Three original methods checked

**1. C-BSN — Yeong Il Jang, Keuntek Lee, Gu Yong Park, Seyun Kim, Nam Ik Cho.** *Self-supervised Image Denoising with Downsampled Invariance Loss and Conditional Blind-Spot Network*, ICCV 2023, pp.12196–12205. Read accepted [CVF PDF](https://openaccess.thecvf.com/content/ICCV2023/papers/Jang_Self-supervised_Image_Denoising_with_Downsampled_Invariance_Loss_and_Conditional_Blind-Spot_ICCV_2023_paper.pdf) §3.1–3.6, Eqs.1–10. Its feature operation is `F_o=(M⊙W)*F_i+b`, with `M=1−δ` when blind and `M=1` otherwise. Shared blind/nonblind networks are trained with reconstruction plus downsampled invariance, `||RS₂(f(x))−stopgrad(f_M(RS₂(x)))||`, and a blind loss. Random subsampling weakens noise correlation. Proposition 1 assumes decorrelated downsampled inputs and bounds supervised risk. **It already establishes center-visible self-supervised learning, but the inspected formulas do not subtract the center using `C_ji/C_ii`.** No code execution/implementation audit. [Author code linked by paper](https://github.com/jyicu/CBSN).

**2. Blind2Sound — Jiazheng Liu, Zejin Wang, Bohao Chen, Hua Han.** *Blind2Sound: Self-Supervised Image Denoising without Residual Noise*, ICCV 2025, pp.12937–12946. Read indexed original [accepted PDF](https://openaccess.thecvf.com/content/ICCV2025/papers/Liu_Blind2Sound_Self-Supervised_Image_Denoising_without_Residual_Noise_ICCV_2025_paper.pdf) §4.2–4.3 Eqs.13–18 and [supplement A.1 Eqs.6–13](https://www.openaccess.thecvf.com/content/ICCV2025/supplemental/Liu_Blind2Sound_Self-Supervised_Image_ICCV_2025_supplemental.pdf), not a complete PDF audit. It combines masked and visible branches, uses adaptive Gaussian likelihood `½(y−μ_y)ᵀΣ_y⁻¹(y−μ_y)+½log|Σ_y|`, and predicts `(μ_m+λμ_v)/(1+λ)`. A noise estimator/GAT constraints support calibration. **No center-conditioned neighbor subtraction appears in the inspected mechanism.** “Two-branch decorrelation” in its prose is not this feature formula. This review does not endorse all mixture/independence derivations. The older arXiv2303.05183v2 (2023-03-14) has different authors; the formulas above are attributed to the accepted 2025 sources, not silently merged with that version.

**3. Adriaan Graas, Felix Lucka.** *Scintillator decorrelation for self-supervised x-ray radiograph denoising*, Measurement Science and Technology 36,065415, published2025-06-19. Read [institution-hosted final PDF](https://ir.cwi.nl/pub/35214/35214.pdf) §§2.4–3.4, especially Eqs.8–15 and Algorithm1. It models `I=H Î`, constructs the global transform `u=H̃⁺I`, and seeks diagonal covariance `H̃⁺(HΛHᵀ+Σ)H̃⁺ᵀ`; Eq.14 supplies a stationary approximation. It estimates a Toeplitz covariance/kernel from repeated static radiograph differences. Noise2Self then masks transformed-domain centers and learns against transformed targets. **This is strong prior art for covariance whitening before blind-spot learning, but differs from keeping the original target and residualizing its neighboring inputs.** Paper CC-BY4.0; linked author code GPL-3.0. No experimental reproduction.

## What survives, and what does not

The narrow distinction surviving this check is **per-target partial orthogonalization while leaving the supervision variable unchanged**. Neither “uses the center” nor “decorrelates noise before self-supervision” is new. Gaussian conditioning itself is established, and prior R2R already defeats the broad covariance-independence theorem claim. Failure to find this exact representation in three papers is not proof nobody has used it. AP-BSN and Spatially Adaptive Self-Supervision were not formula-audited in this final three-method cap.

A mechanism test is defensible only with fixed known covariance first and original-noisy-target supervision. Retain white-noise reduction, perfectly/strongly correlated flat-level failures, repeated texture and covariance misspecification as prespecified falsifiers. Compare masked-input and matched-covariance R2R controls; later add estimated-covariance and real-image tests only if warranted. No anticipated improvement is asserted.

**Implementation pitfall (our reasoning):** all features for target `i` must be residualized against that same `y_i`. Feeding a globally stacked map of features centered at different pixels into an ordinary spatial CNN can restore dependence on `n_i`; the per-target Gaussian independence proof then does not apply. Raw-center bypasses, per-image normalization statistics and covariance estimates reusing target noise likewise need separate analysis. The representation retains some center-dependent signal combinations, not all original information.
