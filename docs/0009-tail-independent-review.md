The implementation counts component rook coefficients using a complete-biclique formula or smaller-side subset DP, then convolves those coefficients before the **global** factorial tail transform. It does not multiply independent component hit probabilities. Empty/zero/full boards and thresholds outside the support are handled with exact integers. Noncomplete components whose smaller side exceeds 12, n>512, or exhausted work budgets yield explicit refusal without an approximate probability.
