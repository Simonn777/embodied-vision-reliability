## What the current family can and cannot do

For an active channel, the implemented write is

`m'_c(x) = m_c(x) + q_c0 * (m_c(x)-mu_c)/sigma_c + q_c1`

`          = alpha_c*m_c(x) + beta_c`.

There are at most two spatial degrees of freedom per channel: its existing activation pattern and a constant map. Thus `m'(x)-m'(y)=diag(alpha)*(m(x)-m(y))`. This **can** amplify already discriminative target channels, suppress nuisance channels, and change later attention/value competition. It is not correct to declare it incapable of identity or boundary improvement. Nor does the energy bound guarantee every alpha is positive: do not claim all within-channel orderings are preserved.

The concrete limitation is **no independent local edit**. The operator cannot add different new residual directions to two positions with identical memory vectors, relocate a feature, or independently suppress one local boundary fragment while preserving another with the same channel response. Native positional encodings and future queries can still distinguish positions; the claim concerns the information added by this correction, not an impossibility theorem for the whole tracker. Exactly constant channels are disabled completely.

The head creates a second restriction: its 131 inputs retain only global channel means/stds, two confidences and mask area. It receives neither the spatial mask nor image-edge/target alignment. A spatial permutation preserves these statistics but may change which local feature belongs to the target. The basis retains spatial structure; the decision about its global coefficients does not observe that structure explicitly.

Finally, the correction occurs **after the current mask is emitted**. Current mask, pointer, position and object score stay unchanged; only the spatial write changes. A bad current pointer or a native no-object spatial embedding is not independently repaired. Later states may change, but the mechanism cannot claim an immediate correction of the current prediction.

These are representation/interface restrictions, not diagnoses inferred from the negative rollout. Surrogate-task mismatch, target predictability, optimization, quantization and one-write versus repeated-write deployment remain separate explanations. The small positive GT-memory learner is evidence of some signal in this restricted family on these parents; it is neither a ceiling nor proof of significance.

## One concrete successor: spatial repair of the storage mask

If the current diagnostic chain remains negative, test **a spatial mask correction used only for memory encoding**, rather than another global memory calibration. A compact zero-initialized local head sees the already cached current frozen image features together with current mask logits and predicts a spatial logit residual. The current emitted mask remains native. Re-encode the corrected storage logits through the frozen native memory encoder and store that spatial memory; leave conditioning frame zero, pointer, position, schedule and object-score policy fixed.

This introduces a specific missing observation—local image/mask disagreement—and an action that can edit one region without uniformly changing the rest. The attainable hypothesis is narrower than identity recovery: a falsely included/excluded boundary region should contaminate later memory less, improving subsequent boundary F without sacrificing region J. It does not promise recovery from visually indistinguishable distractors, total disappearance or a wrong presence decision.

The existing native source supports a differentiated predicted-mask path: `_encode_new_memory(..., is_mask_from_pts=False)` applies sigmoid, the existing scale/bias, mask downsampling and image-feature fusion. It then adds the existing no-object embedding. This is a source-level route, **not qualified training behavior or a runtime guarantee**. Preserve those conventions; do not substitute the GT-prompt hard-threshold path. Zero-correction equivalence and complete extra encoder/backward cost would need qualification. No new image encoder, checkpoint or acquisition is intrinsically required.

**Cheap falsifier before training this head:** on the same already-exposed TRAIN anchor/horizon contexts, compare the full native current-GT-mask-encoded write with its existing channel-affine projection and native memory. If the full spatial write has no useful future J/F opportunity beyond the projection, this proposed escape from the family restriction lacks support; a large feature reconstruction residual alone is not enough. This is a privileged opportunity check, not deployable accuracy, and is proposed only after the current scheduled diagnostics.

A first 96-forward replay of the cached **full** GT write alone is a useful cheaper opportunity screen, not yet the complete projection comparison. Source inspection of `campaign/cache_baselines.py:214–217` shows the cache uses `is_mask_from_pts=True` and GT-derived object-score +/-10: it can change the no-object embedding as well as the mask, and the full replacement has no rho=.15 energy bound. Call it a full GT-mask/presence encoded write. Retain all anchors and report GT/native presence agreement and full-delta energy relative to the original bound; do not infer a pure spatial-locality effect from a positive result. No new encoder is needed to test this existing cached intervention. An adverse result weakens this concrete GT-write route, not every possible local correction.

If opportunity exists, the decisive learner control is the **identical spatial storage-mask head trained on current-mask denoising**, with the same current/future TRAIN annotations available, versus direct future-task training of that head. A matched-capacity version receiving spatially uniform/broadcast image statistics tests whether local alignment adds information rather than merely more parameters. Evaluate complete own rollouts; do not promote an oracle write or frozen-context gain. If ordinary denoising matches the candidate, retain the useful baseline but make no future-credit or distillation claim. Do not simultaneously add pointers, new references, eviction policies and teacher complexity.

## Closest-prior risk and scope

This is a grounded development hypothesis, not a new-method declaration. The existing primary-source review found **MemSAM (CVPR 2024)** already combines predicted masks and spatial image features in a learned foreground-reinforcing/value-encoding module; this is the most direct content-level risk. [Official implementation](https://github.com/dengxl0520/MemSAM), [`mem_modules.py`](https://raw.githubusercontent.com/dengxl0520/MemSAM/main/models/segment_anything_memsam/modeling/mem_modules.py). The earlier review read those code paths, but did not fully read the final paper; no new network request was made here. LWL also already shapes a learned target representation using later segmentation loss ([ECCV 2020 primary paper](https://www.ecva.net/papers/eccv_2020/papers_ECCV/papers/123470766.pdf), previously read methods). Merely adding mask-guided spatial refinement or future supervision would repackage known operations. The remaining empirical question is whether a distinct storage-only correction through the frozen encoder yields useful delayed quality at its complete cost, beyond same-head denoising/direct controls. Any positive pilot would still need a sharper method distinction and the standing independent-source gate.
