Human review should be recorded explicitly when it happens.

Use these labels in research notes:

- **Source checked:** bibliographic details or an abstract were verified at the primary source.
- **Paper reviewed:** named sections/full text were actually read; specify the coverage and remaining questions.
- **Implemented:** code exists and its tests have run; this alone is not a successful experiment.
- **Measured:** an executable run produced the linked raw artifacts, configuration, environment, and summary.
- **Reproduced:** a repeat run or independent implementation matched the stated comparison criterion.
- **Hypothesis:** a proposed explanation or expected effect, not an observation.

Keep observed quantities separate from interpretation. Do not promote a synthetic diagnostic into a real-world robotics finding, a preprint into an accepted paper, or an untested idea into a new method. No affiliation or endorsement by Stanford, NVIDIA, or a conference is claimed.
